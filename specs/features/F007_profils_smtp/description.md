# F007 - Profils SMTP

## Description
Gérer les profils SMTP pour l'envoi des emails.

## Fonctionnalités
1. **Création de Profils** : Permettre la création de profils SMTP.
2. **Configuration des Profils** : Permettre la configuration des paramètres SMTP (serveur, port, authentification, etc.).
3. **Gestion des Profils** : Permettre la modification et la suppression des profils SMTP.
4. **Sélection du Profil** : Permettre la sélection d'un profil SMTP pour l'envoi des emails.
5. **Ajout de Signature HTML** : Permettre l'ajout d'une signature HTML personnalisée pour les emails.

## User Stories
- **US001** : En tant qu'utilisateur, je veux créer un profil SMTP pour configurer l'envoi des emails.
- **US002** : En tant qu'utilisateur, je veux configurer les paramètres SMTP pour un profil.
- **US003** : En tant qu'utilisateur, je veux sélectionner un profil SMTP pour envoyer mes emails.

## Critères d'Acceptation
- Les profils SMTP doivent être créables et configurables.
- Les profils SMTP doivent être modifiables et supprimables.
- Un profil SMTP doit pouvoir être sélectionné pour l'envoi des emails.

## Notes
- Les profils SMTP doivent être stockés dans la base de données.
- Les profils SMTP doivent être sécurisés (chiffrement des mots de passe).
