# F008 - Génération par IA

## Description
Générer des séquences d'emails via des actions utilisateur dans l'application et ChatGPT.

## Fonctionnalités
1. **Génération de Prompts** : Permettre la génération de prompts pour ChatGPT basés sur les données de l'application.
2. **Copie des Prompts** : Permettre aux utilisateurs de copier les prompts générés pour les utiliser dans ChatGPT.
3. **Import des Réponses** : Permettre aux utilisateurs d'importer les réponses de ChatGPT dans l'application.
4. **Validation des Séquences** : Valider les séquences générées avant leur utilisation.

## User Stories
- **US001** : En tant qu'utilisateur, je veux générer un prompt pour ChatGPT basé sur mes données.
- **US002** : En tant qu'utilisateur, je veux copier le prompt généré pour l'utiliser dans ChatGPT.
- **US003** : En tant qu'utilisateur, je veux importer la réponse de ChatGPT dans l'application.

## Critères d'Acceptation
- Les prompts doivent être générés et copiables.
- Les réponses de ChatGPT doivent être importables dans l'application.
- Les séquences générées doivent être validées avant utilisation.

## Notes
- Les séquences générées doivent être stockées dans la base de données.
- Les prompts doivent être configurables via l'interface utilisateur.
