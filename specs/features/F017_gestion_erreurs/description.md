# F017 - Gestion des Erreurs

## Description
Colonnes `error` et `error_details` dans la classe `Relances` pour gérer les erreurs d'envoi.

## Fonctionnalités
1. **Enregistrement des Erreurs** : Enregistrer les erreurs d'envoi dans la classe `Relances`.
2. **Détails des Erreurs** : Enregistrer les détails des erreurs pour un diagnostic.
3. **Affichage des Erreurs** : Afficher les erreurs dans l'interface utilisateur.
4. **Gestion des Erreurs** : Permettre la correction et la réexécution des envois.

## User Stories
- **US001** : En tant qu'utilisateur, je veux être informé des erreurs d'envoi.
- **US002** : En tant qu'utilisateur, je veux voir les détails des erreurs.
- **US003** : En tant qu'utilisateur, je veux corriger et réessayer l'envoi.

## Critères d'Acceptation
- Les erreurs doivent être enregistrées dans la classe `Relances`.
- Les détails des erreurs doivent être accessibles.
- Les erreurs doivent être affichées dans l'interface.

## Notes
- Les erreurs doivent être enregistrées avec un statut et des détails.
- Les erreurs doivent être gérables via l'interface utilisateur.
