# F011 - Calendrier des Relances

## Description
Afficher les relances dans un calendrier ou un tableau.

## Fonctionnalités
1. **Affichage en Calendrier** : Permettre l'affichage des relances dans un calendrier.
2. **Affichage en Tableau** : Permettre l'affichage des relances dans un tableau.
3. **Filtrage des Relances** : Permettre le filtrage des relances par date, statut, ou autre critère.
4. **Export des Relances** : Permettre l'export des relances au format CSV ou Excel.

## User Stories
- **US001** : En tant qu'utilisateur, je veux afficher les relances dans un calendrier.
- **US002** : En tant qu'utilisateur, je veux afficher les relances dans un tableau.
- **US003** : En tant qu'utilisateur, je veux filtrer les relances par date ou statut.
- **US004** : En tant qu'utilisateur, je veux modifier les messages de relance de manière unitaire.

## Critères d'Acceptation
- Les relances doivent être affichables dans un calendrier ou un tableau.
- Les relances doivent être filtrables par date, statut, ou autre critère.
- Les relances doivent pouvoir être exportées.

## Notes
- Les relances doivent être liées aux factures et aux séquences correspondantes.
- Les relances doivent être mises à jour en temps réel.
