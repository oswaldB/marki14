# F009 - Gestion des Contacts Sans Email

## Description
Identifier et afficher les contacts sans email, avec le montant et le nombre de factures impactées.

## Fonctionnalités
1. **Identification des Contacts** : Identifier les contacts sans adresse email.
2. **Affichage des Contacts** : Afficher les contacts sans email dans une interface dédiée.
3. **Informations Associées** : Afficher le montant et le nombre de factures impactées pour chaque contact.
4. **Export des Données** : Permettre l'export des données des contacts sans email.

## User Stories
- **US001** : En tant qu'utilisateur, je veux que les contacts sans email soient identifiés automatiquement.
- **US002** : En tant qu'utilisateur, je veux afficher les contacts sans email dans une interface dédiée.
- **US003** : En tant qu'utilisateur, je veux exporter les données des contacts sans email.

## Critères d'Acceptation
- Les contacts sans email doivent être identifiés et affichés.
- Les informations associées (montant et nombre de factures) doivent être affichées.
- Les données doivent pouvoir être exportées.

## Notes
- Les contacts sans email doivent être mis en évidence dans l'interface.
- Les données exportées doivent être au format CSV ou Excel.
