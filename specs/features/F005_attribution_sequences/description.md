# F005 - Attribution des Séquences

## Description
Attribuer des séquences aux factures impayées de manière unitaire ou groupée.

## Fonctionnalités
1. **Attribution Unitaire** : Permettre l'attribution d'une séquence à une facture individuelle.
2. **Attribution Groupée** : Permettre l'attribution d'une séquence à plusieurs factures simultanément.
3. **Filtrage des Factures** : Permettre de filtrer les factures pour une attribution groupée.
4. **Gestion des Attributions** : Permettre la modification ou la suppression des attributions.

## User Stories
- **US001** : En tant qu'utilisateur, je veux attribuer une séquence à une facture individuelle.
- **US002** : En tant qu'utilisateur, je veux attribuer une séquence à plusieurs factures en même temps.
- **US003** : En tant qu'utilisateur, je veux filtrer les factures pour une attribution groupée.

## Critères d'Acceptation
- Les séquences doivent pouvoir être attribuées à des factures individuelles ou groupées.
- Les attributions doivent être modifiables ou supprimables.
- Les factures doivent pouvoir être filtrées pour une attribution groupée.

## Notes
- Les attributions doivent être enregistrées dans la base de données.
- Les séquences attribuées doivent être visibles dans l'interface utilisateur.
