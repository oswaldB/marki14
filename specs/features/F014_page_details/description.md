# F014 - Page Détails de l'Impayé

## Description
Afficher les détails et les actions pour chaque facture impayée.

## Fonctionnalités
1. **Affichage des Détails** : Afficher les détails complets d'une facture impayée.
2. **Historique des Actions** : Afficher l'historique des actions effectuées sur la facture.
3. **Gestion des Actions** : Permettre l'ajout et la modification des actions.
4. **Affichage des Relances** : Afficher les relances associées à la facture.

## User Stories
- **US001** : En tant qu'utilisateur, je veux afficher les détails d'une facture impayée.
- **US002** : En tant qu'utilisateur, je veux voir l'historique des actions sur une facture.
- **US003** : En tant qu'utilisateur, je veux ajouter une action à une facture.

## Critères d'Acceptation
- Les détails des factures doivent être affichables.
- L'historique des actions doit être visible.
- Les actions doivent pouvoir être ajoutées et modifiées.

## Notes
- Les détails doivent inclure les informations de la facture, du contact, et des relances.
- Les actions doivent être enregistrées dans la base de données.
