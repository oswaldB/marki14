# F006 - Lien de Paiement

## Description
Intégrer des liens de paiement personnalisables dans les séquences, avec des variables dynamiques.

## Fonctionnalités
1. **Création de Liens** : Permettre la création de liens de paiement personnalisés.
2. **Utilisation de Variables** : Permettre l'utilisation de variables dynamiques dans les liens de paiement.
3. **Gestion des Liens** : Permettre la modification et la suppression des liens de paiement.
4. **Intégration dans les Emails** : Permettre l'intégration des liens de paiement dans les templates d'emails.

## User Stories
- **US001** : En tant qu'utilisateur, je veux créer un lien de paiement personnalisé pour mes emails.
- **US002** : En tant qu'utilisateur, je veux utiliser des variables dynamiques dans mes liens de paiement.
- **US003** : En tant qu'utilisateur, je veux intégrer un lien de paiement dans mes templates d'emails.

## Critères d'Acceptation
- Les liens de paiement doivent être personnalisables.
- Les variables dynamiques doivent être utilisables dans les liens de paiement.
- Les liens de paiement doivent être intégrables dans les templates d'emails.

## Notes
- Les liens de paiement doivent être stockés dans la base de données.
- Les liens de paiement doivent être accessibles via l'interface utilisateur.
