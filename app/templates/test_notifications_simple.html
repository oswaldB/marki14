Système de Notifications

Testez les différents types de notifications

📋 Exemples d'utilisation

Dans un template HTML :

<button
  @click="$store.notifications.addNotification('Message', 'success')"
>
  Cliquez-moi
</button>

Dans du JavaScript :

// Notification simple
$store.notifications.addNotification('Opération réussie', 'success');

// Avec durée personnalisée
$store.notifications.addNotification('Chargement...', 'info', 10000);

Après une requête AJAX :

fetch('/api/save', { method: 'POST', body: data })
  .then(response => {
    if (response.ok) {
      $store.notifications.addNotification('Sauvegardé!', 'success');
    } else {
      $store.notifications.addNotification('Erreur', 'error');
    }
  });
