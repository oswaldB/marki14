# Store index.js

## Description
Fichier d'entrée pour tous les stores Alpine.js. Ce fichier sert de point d'entrée pour initialiser et référencer tous les stores Alpine.js utilisés dans l'application. Il est chargé automatiquement lors de l'initialisation de l'application.

## Comportement
- **Initialisation** : Charge et initialise tous les stores Alpine.js nécessaires.
- **Journalisation** : Enregistre un message dans la console pour indiquer que les stores ont été chargés.

## Fonctions
Aucune fonction spécifique n'est définie dans ce fichier. Il sert principalement à importer et référencer les stores Alpine.js.

## Dépendances
- **Alpine.js** : Bibliothèque JavaScript pour la réactivité et la gestion des états.

## Exemples d'Utilisation
- Ce fichier est chargé automatiquement lors de l'initialisation de l'application.
- Il est utilisé pour s'assurer que tous les stores Alpine.js sont disponibles et initialisés.

## Structure
```
app/
└── static/
    └── js/
        └── stores/
            └── index.js
```
